## 🚀 How to Build the APK in Android Studio

1. Open **Android Studio**.
2. Select **Open** and choose the folder:
   `app/android_studio_project/`
3. Wait for Gradle sync to complete.
4. To generate the APK:
   - Go to menu: **Build** > **Build Bundle(s) / APK(s)** > **Build APK(s)**
   - Once finished, click **locate** to get the output `app-debug.apk`.
5. Install on any Android device (supports Android 5.0 Lollipop through Android 14+).
